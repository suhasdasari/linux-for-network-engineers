# Linux for Network Engineers

FloorKit field edition. From first SSH to a live camera box.

A short Linux handbook for campus and field network engineers who already know switches. Not a sysadmin degree. Not hacking.

## What’s in it

- **Part 0** — Lab VM, bridged vs NAT, snapshots, SSH
- **Part 1** — Shell, files, permissions
- **Part 3** — `ip`, routes, DNS, sockets, tcpdump, fault table
- **Part 5** — Closet appliance, no-video checklist, Docker field kit
- **Part 7** — Ten timed live CLI drills
- **Part 8** — Printable 20-command field card

Core path: **1 → 3 → 5 → 7**.

## Run

```bash
npm install
npm run dev
```
